## 2. 下载与完整性校验

1. 从交付目录下载两个安装包（正式版、QA 版）。
2. 打开 PowerShell，进入下载目录：

   ```powershell
   Get-FileHash .\*.exe -Algorithm SHA256 | Format-Table -AutoSize
   ```

3. 把输出的值与 `SHA256SUMS.txt` 逐行对比。**不一致就不要安装**，重新下载。

## 3. Windows 系统要求

- Windows 10（1809 及以上）或 Windows 11，64 位。
- 至少 300 MB 可用磁盘空间（应用本体 + 数据）。
- 首次安装需要联网：安装程序会检查并下载 **WebView2 Runtime**（微软的网页组件，很多 Windows 已自带）。

### 检查 WebView2 是否已安装

`设置 → 应用 → 已安装的应用`，搜索 `WebView2`：

- 有 `Microsoft Edge WebView2 Runtime` → 直接安装应用即可。
- 没有 → 保持联网，安装程序会自动引导下载；若失败，去微软官网搜 "WebView2 Runtime Evergreen Bootstrapper" 手动装一次。

## 5. QA 版：两个场景的启动方式（重点）

QA 版有**两套互相隔离的数据**，启动方式不同：

| 场景 | 怎么启动 | 看到什么 | 数据位置 |
| --- | --- | --- | --- |
| **seeded**（预置演示数据） | 双击桌面/开始菜单的 QA 图标 | 十几条演示订单，方便看界面 | `%APPDATA%\dev.artflow.minidesk.qa\seeded` |
| **clean**（空白） | 双击交付目录里的 `启动 QA Clean（空白环境）.cmd` | 0 条订单，像新装的软件 | `%APPDATA%\dev.artflow.minidesk.qa\clean` |

- 两套数据互不影响；删掉其中一个不会动另一个。
- 正式版数据在另一个目录，QA 怎么折腾都不影响正式版。
- 脚本只对本次启动生效，**不会**改系统环境变量，也不需要装任何开发工具。

## 15. 反馈方式

1. 复制本文件，在「结果」列填 `PASS` / `FAIL` / `PARTIAL` / `NOT RUN`。
2. 每张截图命名为 `T编号.png`（例：`T29.png`），与文件放在同一目录。
3. FAIL 项请补充：当时的操作、是否可复现（关掉应用重试一次还出现吗）、系统版本与缩放比例。

反馈时把整份 MD + 截图目录一起发回即可。
