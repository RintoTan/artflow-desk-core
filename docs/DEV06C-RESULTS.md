### 1.1 排期轨道怎么放

放在 `.order-row-meta` 这一行的右侧（`margin-left: auto`，96×14px），**不新增行高**。
这不是省事，是必须：UI-06 换来的"一屏 3 条"正是靠 78px 的行高，加一行 16px 就会掉到 2 条。

```
AF-2026-0001                                    [活动]
双完成演示稿
● 制作中 · 线稿 · 林小满                 ▭▬▬▬○│┃ ───────
                                        ↑计划  ↑开工 ↑交付  ↑今天
```

- 区间 `▬▬▬` = 计划开始 → 计划交付（浅蓝底令牌）
- `┃` 交付标记：颜色取后端 `deadlineState`（逾期红 / 今天 / 三日内 / 未排期灰）
- `○` 实际开工：空心圆（与"计划"的竖条形状不同，不会被误读成计划开始）
- `●` 完成 / `▢` 取消：中性色，终态订单不染风险色
- `↑今天` 竖线：窗口中点，`--text-faint` 75% 透明
- 左右边缘出现三角形 = 该日期在 ±45 天窗口之外（不伪装成边界当天）

### 1.2 图表结构

```text
[Y轴 34px] [ .chart-scroll  ← 只有这里横向滚动 ]
  10 ──────┼──────────────────────────────  ← 网格线（0/5/10）
   5 ──────┼──▮──▮────▮──▮────▮─────▮─────
   0 ──────┴──┴──┴────┴──┴────┴─────┴─────
            25-12 26-01 ...            26-11
```

- Y 轴是 `.chart-frame` 的第一列，**在滚动容器之外**，横向滚动时纹丝不动（已实测，见 §4）
- 网格线在滚动内容里，跟着柱子走，保证与刻度对齐
- 数值标签绝对定位在柱顶上方 3px，向上溢出进预留的 14px padding
- 柱列 `tabIndex=0`，`aria-label` = `2026-11：新建 10、完成 2、取消 1`
- 悬停/聚焦弹数值气泡：portal 到 body + `position: fixed`，不会被滚动容器裁切
- 图表容器是 `role="group"`（不再用 `role="img"`——里面有可聚焦子元素）

## 2. 时间轴模型与边界处理

### 2.1 日期算法（三条硬规则）

1. **日历日整数运算**：`daysFromCivil` / `civilFromDays`（Hinnant 算法），全程不用
   `毫秒 / 86400000`。闰年、跨世纪、夏令时都只是"第几天"的加减。
2. **UTC → 工作时区日历日**用 `Intl.DateTimeFormat(..., {timeZone}).formatToParts()`，
   按 `type` 取值，**不解析本地化字符串**（`03/04/2026` 谁是月谁是日不该靠约定）。
3. **风险分类只读** `deadlineState`，前端不重算逾期/今天/三日内。

### 2.2 各类边界

| 情况 | 行为 |
|---|---|
| 双日期 | 画区间 + 交付标记 |
| 只有交付日 | 只画交付标记，**不推算开始** |
| 只有计划开始 | 只画 `planStart` 标记（细灰条），不推算交付 |
| 两个都空 | 什么都不画，`<sched>` 节点直接不渲染 |
| 计划开始 > 计划交付 | `invalidRange`：不画区间，两个点仍在，界面照常可用 |
| 日期在窗口外 | 钳在 0%/100% 并加方向三角，`data-overflow` 可断言 |
| 非法日期（`2026-02-30`） | `parseDayKey` 返回 null，当"没有这个日期"处理，不崩 |
| 坏时区名 / 坏时间戳 | 返回 null，不抛异常（`Intl` 的 `RangeError` 被吃掉） |
| 终态订单 | 交付标记与区间转中性；`completed`/`cancelled` 标记只认当前状态字段 |
| 重开订单 | 不读历史事件，只用当前 `startedAt`，不虚构排期 |
| 实际开工 | 空心圆标记，**不会**被画成计划开始 |

窗口固定为「今天 ±45 天」，所有行共用；搜索、筛选、排序都不改变窗口，否则同一批订单的
长短会随筛选条件变来变去。
