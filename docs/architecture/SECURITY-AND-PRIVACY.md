# 安全与隐私

## 数据边界

| 数据 | 位置 | 是否离开本机 |
| --- | --- | --- |
| 业务数据（订单/客户/事件/附件） | 应用数据目录 | 否 |
| 备份包 | 用户自选位置 | 否（由用户自行保管） |
| 日志 | 进程 stdout | 否 |

应用不发起任何网络请求，不集成分析 SDK，不收集遥测。

## 资产协议（本地图片访问）

- 通过 Tauri 的 `asset` 协议在 WebView 中加载本地图片；
- 静态 `assetProtocol.scope` 为**空**，启动时只对**当前活动代际**的 `attachments` 目录做 `allow_directory`；
- 协议层会先把路径解析为真实路径（跟随符号链接）再比对授权范围，因此「指向外的符号链接」同样被拒。

已实测（macOS 真实 WKWebView，开发环境与打包环境各一轮）：合法缩略图正常加载；`../`、编码穿越、双重编码、AppData 内/外 canary、`/etc/passwd`、`database.sqlite`、跨代际直连、跨代际符号链接全部被拒。

Windows（WebView2）使用 `http://asset.localhost/…`，同一套 scope 机制，但**尚未在 Windows 实机验证**。

## 路径安全

- 附件只以「相对路径」入库，绝对路径在读取时拼装并做前缀校验；
- 备份包解包时拒绝绝对路径、`..`、盘符、重复条目、符号链接；
- 恢复解包目标必须在新建代际目录内。

## 备份包与隐私

备份包**未加密**，内含客户姓名、联系方式、订单金额与图片。请：
- 存放在可信位置；
- 不要通过公开渠道传输；
- 需要分享截图时，使用 QA 环境的虚构数据。

## 隐私说明

QA 环境内置演示数据（编号 `AF-2026-xxxx`、虚构客户名），用于截图与演示，不含真实客户信息。
正式环境数据只存在用户本机，开发者无法访问。
