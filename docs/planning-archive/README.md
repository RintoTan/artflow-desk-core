- 这些文件里的路径是**当时**的本机绝对路径（`/Users/...`），保留原样以便追溯；
- 文件中出现的阶段编号（DEV-06D-3-UI-08 等）不再作为当前版本的功能编号；
- 有些"待办"在后续阶段已完成或已明确砍掉，判断当前状态请看
  [PRODUCT-ROADMAP.md](../product/PRODUCT-ROADMAP.md)。
