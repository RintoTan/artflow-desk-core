**状态：** `DEV-06D-1 = OPEN / PARTIALLY ACCEPTED`，等 SETTINGS-QA 实机验收。

**参考原型：** 用户提供的「ArtFlow Desk Core 设置页新版宽屏原型」截图（附件 `image-1794982884197.png`）。本轮只参考其**组织方式与视觉关系**：页头、双栏模块、浅色冷调卡片、紧凑图标卡、集中保存栏。未做像素级复制。

## 一、正式布局

```
设置（页头：图标 + 标题 + 一句用途）
┌───────────────────────────┬──────────────────────────┐
│ 外观                      │ 强调色                    │
│  用户选择 / 当前 / 已保存  │  色卡 + HEX + 用默认色     │
│  主题模式（分段控件）      │                           │
│  当前主题预览             ├──────────────────────────┤
├───────────────────────────┤ 应用图标                  │
│ 工作时区                  │  Orbit / Layers / Wave A   │
│  当前 / 系统时区 / IANA    │  32px 实际大小 / 恢复默认  │
└───────────────────────────┴──────────────────────────┘
本阶段尚未提供的设置（整行，说明性文字）
[ 保存设置 | 放弃修改 | 恢复默认主题 ]（吸底保存栏）
```

- 断点按设置内容容器宽度（`@container workspace`）判断：**≥900px 双栏**，**<900px 单栏**。
  - 1400px 窗口内容 1085px → 双栏；1680px → 双栏更宽；1100px 内容约 785px → 单栏；900px → 单栏。
  - 之所以把阈值定在 900 而不是 760：1100px 窗口下双栏只剩 ~370px 给外观模块，主题模式标签会折成两行、状态值被截断，违反「保持双栏必须保证控件可读」。
- 两列各自是独立的纵向栈（`.settings-col`），模块高度不同不会互相拉伸，也不会有卡片被强行撑高。
- 外观模块内部：左侧控件、右侧 188px 主题预览；容器 <640px 时隐藏预览，只留控件。
- 窄栏（<640px）保存栏改为纵向堆叠，按钮等宽。

## 三、控件与视觉

- 统一：模块 `padding: 18px 20px 20px`、模块间距 16px、表单控件 `min-height: var(--control-h)`、按钮 8px 间距、圆角 `--radius-sm`。
- Focus：沿用全局 `:focus-visible`；图标卡保留 `outline: 2px solid var(--accent)`；强调色模块 hover 不改变选中态。
- Disabled：保存/放弃在无改动时禁用，恢复默认在 busy 时禁用。
- 深色主题：全部使用既有语义变量（`--surface`、`--surface-alt`、`--border`、`--accent`、`--accent-soft`），没有新增硬编码色值；深色截图见 05。

## 四、保存区域

- 三段：状态文案（未保存/已保存）、保存设置（主色）、放弃修改、恢复默认主题（次色）。
- 保存成功显示 notice-ok，失败显示 `role="alert"`；状态文字随 `dirty` 变化。
- 「恢复默认主题」现在先弹确认框（标题「恢复默认主题？」、确认「恢复默认」、取消「保留当前设置」），正文说明只改草稿、保存后才写入；取消不会动草稿。
- 保存栏 `position: sticky; bottom: -1px`；**窗口高度 ≤560px 时改为随内容排列**，避免矮窗口里盖住半个模块。

## 七、未完成与风险

1. **Mac WKWebView 全部 NOT RUN**：吸底栏在 WKWebView 的 `backdrop-filter`、滚动边缘、`100dvh` 表现都只有 Blink 证据。
2. **深色只截了 1400**：900/1100 深色未出图；深色一致性依赖变量与既有守卫。
3. **原型中的「打开目录 / 清理缓存 / 高级选项」未实现**，也没有占位控件；需要产品另行立项（涉及 Rust 侧命令）。
4. **恢复默认主题只重置草稿**，不是"恢复并立即保存"；与旧行为一致，但确认框文案已写明。
5. **窄卡片隐藏「浅色/深色」文字标签**：图标预览仍在，只是文字说明在 3 张一排时隐藏；如需保留文字，需要把图标模块改为整行。
6. 设置页没有独立的「上次保存时间」——后端未提供该字段，未虚构。
