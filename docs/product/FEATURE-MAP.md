# 功能地图

状态定义：**已实现** = 代码中存在且可用；**部分** = 有基础能力但有明确边界；**未提供** = 代码中不存在。

## 工作台

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 订单状态计数 | 已实现 | 活动 / 排队 / 制作中 / 未排期 |
| 到期提醒 | 已实现 | 三日内、今天、已逾期 |
| 本月完成次数 | 已实现 | 按完成事件计数，同一订单再次完成会再计一次 |
| 跨订单项目时间线 | 已实现 | 只读，日/周/月/年四尺度 |

## 订单

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 新建 / 编辑 / 复制 / 取消 | 已实现 | 编号 `AF-YYYY-NNNN`，先预留后创建，允许空号 |
| 三种视图 | 已实现 | 卡片 / 看板 / 表格 |
| 搜索与筛选 | 已实现 | 标题、编号、客户、来源；按流程与阶段筛选 |
| 队列排序 | 已实现 | 拖动调整，不影响编号 |
| 阶段推进 / 返工 | 已实现 | 一次一级；返工可回到任意更早阶段 |
| 阶段跳级 | 已实现 | 至少跨一个中间阶段，记录被跳过阶段快照 |
| 制作历史 | 已实现 | 推进、返工、跳级、改期、状态变化 |
| 完成 / 取消 / 重新打开 | 已实现 | 终态守护在后端 |
