# 产品概览

## 一句话

给独立画师用的本地委托台账：接单、排期、画到哪一步、什么时候交付，都在一个地方。

## 目标用户

- 独立接单的画师（个人，或一到两人的小工作室）。
- 委托来源分散在私信、邮件、平台站内信，靠记忆和聊天记录管理容易漏单。
- 不愿意把客户信息放到云端服务里。

## 解决的问题

| 痛点 | 现在的做法 |
| --- | --- |
| 单子多了记不清进度 | 一笔订单一条记录，阶段推进留痕 |
| 客户改期后对不上 | 计划日期与改期历史分开记录，实际完成时间来自事件 |
| 参考图散落在聊天窗口 | 附件挂在订单上，原图与缩略图本地保存 |
| 换电脑怕丢数据 | 整库 + 附件的备份包，可整体迁移 |

## 能力边界

**做**：单机、单画师、本地数据、可迁移、可备份恢复。

**不做**（截至 v0.1.0-demo.2）：云同步、多设备实时同步、多用户权限、客户自助门户、在线支付、作品集对外发布、自动定时备份。

## 与 Web 版的关系

ArtFlow Desk（Web）与 ArtFlow Desk Core（桌面）同属 ArtFlow Desk 产品体系，但：

- 代码库独立；
- 数据独立，不共享数据库；
- 发布独立。

两者不是同一个应用的两个入口。
