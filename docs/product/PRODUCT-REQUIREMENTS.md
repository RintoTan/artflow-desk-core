# 需求清单（v0.1.0）

从历史规划中整理，按实现状态分类。**未实现的内容不得当作现有功能宣传。**

## 已实现

### 订单
- 新建 / 编辑 / 复制 / 取消 / 完成 / 重新打开
- 编号 `AF-YYYY-NNNN`：先预留后创建，允许空号
- 队列排序（拖动，不影响编号）
- 三种视图：卡片 / 看板 / 表格
- 搜索（标题、编号、客户、来源）+ 按流程/阶段筛选

### 制作流程
- 每个订单持有自己的阶段副本（来自模板）
- 一次推进一级；返工可回到任意更早阶段
- 跳级：至少跨一个中间阶段，记录被跳过阶段快照
- 阶段名称快照写入事件，改模板不改写历史
- 终态（完成/取消）不可推进或返工

### 客户
- 新建 / 编辑 / 删除（无订单引用时）
- 标签分类
- 订单关联与客户下钻

### 日历与排期
- 月视图 / 周视图，连续纵向滚动
- 计划开始/交付日期绘制
- 拖放改期、未排期订单改期，写入 `rescheduled` 事件
- 「今天」定位保留视口中心日期

### 统计
- 月度完成次数与收入
- 客户 / 模板维度下钻
- 按当前筛选导出 CSV

### 附件
- 多选导入、拖拽导入，逐文件结果反馈
- 原图/缩略图分离，缩略图可重建
- 大图预览（缩放/平移）
- 隔离文件与作业记录：只读盘点 + 手动清理

### 备份与恢复
- 导出 ZIP：一致性快照 + 附件 + manifest + SHA-256
- 恢复：隔离代际、恢复前自动快照、失败不动现有数据
- 编号高水位逐年取大，永不回退
- 应用内备份提醒（无后台任务）

### 设置与关于
- 主题（浅色/深色/跟随系统）、强调色、应用图标
- 工作时区
- 关于软件页承载版本、归属与数据环境信息

## 部分实现

| 需求 | 边界 |
| --- | --- |
| 快捷键 | 仅页面级：⌘N/⌘S/⌘F/↑↓/Enter/Esc；无全局热键 |
| 备份提醒 | 只在设置页显示，无系统通知 |
| 数据维护 | 只支持手动清理，无自动清理策略 |

## 未实现

- 永久删除订单、回收站、自动归档
- 画廊 / 作品集模块、多订单图片引用、阶段级图片
- 自动定时备份、备份包加密
- 云同步、多设备同步、多用户权限、客户自助页面
- 旧数据代际清理入口
- Windows 与 macOS 备份互恢复

## 已明确延期 / 被替代

| 项 | 结论 |
| --- | --- |
| 「数据环境」独立页面 | 已被「关于软件」合并取代 |
| macOS 交叉编译 Windows | 已放弃，改为 GitHub Actions 原生 Windows 构建 |
| 永久删除作为备份前置条件 | 已移除，不再阻塞备份功能 |
