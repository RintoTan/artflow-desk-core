## 状态口径

本文只用四个词描述非完成项，避免把「测试通过」写成「验收通过」：

| 标签 | 含义 |
| --- | --- |
| **代码完成** | 实现存在，自动化覆盖不全或有已知缺口 |
| **自动化通过** | 测试覆盖，尚未上实机 |
| **待验收** | 实现 + 自动化都完成，实机未做 |
| **实机通过** | 产品负责人在真实窗口 / 机器上确认过 |
