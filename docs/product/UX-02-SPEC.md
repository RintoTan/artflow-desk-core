# UX-02 · 窗口布局与 DPI 验收规格

状态：**三批均已实施**（Batch A / B / C；自动化与 CSS 规则断言通过，原生窗口观察仍未完成，见 PROJECT-STATUS）
适用版本：v0.1.1 及以后
上位文档：[PRODUCT-OVERVIEW](PRODUCT-OVERVIEW.md)、[ROADMAP](ROADMAP.md)

---

## 1. 范围

本规格只覆盖「窗口尺寸与系统缩放如何影响布局」，不涉及交互、快捷键、业务流程。

| 覆盖 | 不覆盖 |
| --- | --- |
| 窗口最小 / 默认 / 宽屏尺寸下的布局降级 | 颜色、字体、图标等视觉风格 |
| Windows 100% / 125% / 150% / 200% 缩放 | macOS 系统级字体大小（应用不跟随） |
| 侧栏展开 / 折叠两种状态下内容区宽度变化 | 打印、导出排版 |
| 表格、看板、日历、设置的内容密度 | 移动端（桌面应用无此形态） |

## 2. 布局基线

| 项 | 值 | 来源 |
| --- | --- | --- |
| 默认窗口 | 1120 × 760 | `tauri.conf.json` |
| 最小窗口 | **880 × 500**（Batch B 已实施） | 同上 |
| 侧栏宽度 | 232 px（展开）/ 68 px（折叠） | `styles.css` |
| 断点载体 | 内容区容器 `workspace`、详情容器 `detail`、表格容器 | `container-type: inline-size` |
| 降级顺序 | 两栏 → 单栏（≤780）→ 紧凑表单（≤560） | `@container workspace` |

**原则**：布局降级看「内容区还剩多宽」，不看窗口宽。侧栏折叠后内容区变宽、窗口不变，媒体查询会判断错。

## 3. 验收矩阵

### 3.1 尺寸 × 平台

| 尺寸 | macOS | Windows |
| --- | --- | --- |
| 880 × 500（最小） | 必测 | 必测 |
| 1120 × 760（默认） | 必测 | 必测 |
| 1440 × 900 | 必测 | 抽测 |
| 1600 × 1000（宽屏） | 必测 | 抽测 |

### 3.2 系统缩放（仅 Windows）

| 缩放 | 1920 × 1080 下可用 CSS 尺寸 | 要求 |
| --- | --- | --- |
| 100% | 1920 × 1040 | 窗口可完整放下，无溢出 |
| 125% | 1536 × 832 | 同上 |
| 150% | 1280 × 693 | 同上（已实测通过） |
| 200% | 960 × 520 | 同上（最小窗口已降到 500，配置可达；原生未实测） |

## 4. 判定标准

每一条都必须**可观察、可复现**，不写「看起来正常」。

| 编号 | 判据 | 方法 |
| --- | --- | --- |
| L-1 | 页面无横向滚动 | `documentElement.scrollWidth − clientWidth ≤ 1` |
| L-2 | 无内容被裁切 | 表格右端、卡片金额、按钮文字完整可见 |
| L-3 | 无相互遮挡 | 吸顶元素不盖住可点内容；浮层不压住输入框 |
| L-4 | 关键操作可达 | 保存栏、危险操作区、侧栏折叠按钮在视口内 |
| L-5 | 关键信息不缺列 | 订单表格：编号 / 委托 / 阶段 / 交付金额四列始终保留 |
| L-6 | 局部滚动是有意的 | 看板与表格允许局部横滚，但不得裁切内容 |

### Batch A · CSS 体验修复（已实施）

| 验收项 | 判据 |

### Batch B · DPI 兼容（已实施）

| 验收项 | 判据 |

| 200% 可完整放下 | 1920×1080 @200%：窗口完整落在屏幕内，底部保存栏可达 |

### Batch C · 断点口径统一（已实施）

| 验收项 | 判据 |
| --- | --- |
| 侧栏两态 | 展开 / 折叠 × 880/1120/1440，日历工具栏不重叠、左池不挤压网格 |

## 6. 记录方式

验收结果写入 `docs/releases/PROJECT-STATUS.md`，格式：

```
环境：<平台> <版本> · <缩放> · 窗口 <宽×高>
Batch <X>：PASS / FAIL
未通过项：<编号> <现象> <截图或数值>
未验证项：<编号> <原因>
```

**任何一项未实测，必须写「未验证」而不是留空。** 不同引擎的结论不能互相替代：Chromium 的测量不等于 WKWebView 或 WebView2 的实机结论。
