# 已知限制

## 通用

| 项 | 说明 |
| --- | --- |
| 未签名 / 未公证 | macOS 首开需右键打开；Windows 会有 SmartScreen 提示 |
| 无自动备份 | 只有手动导出 + 应用内提醒 |
| 备份未加密 | 含客户信息，注意保管 |
| 无许可证 | 未指定公开许可证，不代表可自由分发或修改 |
| 单机单用户 | 无云同步、无多用户、无客户自助页面 |
| 永久删除未提供 | 订单只能取消或完成，不能物理删除 |
| 画廊 / 作品集未提供 | 参考图不会流向任何展示模块 |

## macOS

| 项 | 说明 |
| --- | --- |
| 仅 Apple Silicon | 未构建 Intel / Universal |
| 仅 `.app` → `.dmg` | 未提供 App Store 或 pkg 安装 |
| 正式版未在本机启动 | 为保护本机正式数据，正式包只做了静态核验，运行验收全部用 QA 包 |
| 本版产物未做运行验收 | demo.2 的 macOS 资产由 DEV-10 重新打包，只做静态复核；DEV-08 的 13 项 PASS 属该批次结论，不能直接沿用 |

## Windows

| 项 | 说明 |
| --- | --- |
| 系统级兼容未验证 | 2026-11-20 已完成真机两阶段功能验收（56 项，核心功能基本通过），但安装/卸载/重装、SmartScreen、DPI 125%/200%、中文路径导入、断网启动仍全部未执行（T01–T40 NOT RUN） |
| 部分功能项未完成 | 16 张附件逐张预览、编号接续、备份导出、完成月归属收入口径、事件级明细、客户页搜索（界面无该控件）在真机上未执行或被环境阻断 |
| 已记录 5 个 P3 | 状态列英文枚举、恢复后 QA 横幅仍显示「空白场景」、QA 构建左下角 DEV-06A 标注、恢复预览缺工作时区、月视图滚动后表头滚出 |
| 单实例提示 | 同一数据目录只允许一个实例；第二个实例会弹出「已有实例在运行」并退出，不会聚焦已有窗口 |
| 仅 x64 | 未构建 arm64 |
| 打包带入开发 CLI | `minidesk-probe` / `attachments-probe` / `qa_seed` 会被一起打包（功能不受影响，体积偏大） |
| QA 默认进演示数据 | 需要空白环境要用 `启动 QA Clean（空白环境）.cmd` |
