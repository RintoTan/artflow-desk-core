## 三之八、0.1.2 交付准备（2026-11-26）

三项改动，只增不删：正式包瘦身、登录自启动、撤回统计页吸顶。

### 1. 正式包排除开发 CLI（P0，已实测）

**根因**：`tauri build` 用 `--bins` 构建，会把 `target/release/` 下所有可执行文件拷进 `Contents/MacOS/`。所以「打包时排除」不能靠事后删除，只能让它们根本不参与构建。

**改法**：三个开发程序（`minidesk-probe` / `attachments-probe` / `qa_seed`）都加 `required-features = ["devtools"]`，新增空特性 `devtools`。依赖这些二进制的三组集成测试（`lock` / `numbering` / `attachments_recovery`）同步加 `#![cfg(feature = "devtools")]`，`npm run qa:seed*` 七个脚本补上 `--features devtools`。

**实测**：

| 项 | 改前 | 改后 |
| --- | --- | --- |
| 包体 | 35.03 MiB | **22.06 MiB** |
| `Contents/MacOS` | 主程序 + 3 个开发 CLI（约 13.6 MB） | **只有 `artflow-minidesk`** |
| 主程序二进制 | — | 与 `target/release/artflow-minidesk` SHA-256 一致（打包没改动主程序） |
| `Info.plist` | — | `CFBundleIdentifier` / `CFBundleShortVersionString` 均为 `dev.artflow.minidesk` / `0.1.2` |

**测试口径变化（必须记住）**：完整 Rust 测试改为 `cargo test --features devtools`。不加特性时，上述三组子进程用例整份跳过，不是「通过」。

**实测基线（2026-11-26，本节写作时）**：`cargo test --features devtools --no-fail-fast` → **Rust 720 passed / 0 failed**；前端 `npx vitest run` → **96 文件 / 953 passed**；`tsc --noEmit` 与 `npm run build` 通过。不带特性的 `cargo test --no-run` 也能编译，只是少跑那三组。**当前基线见 §三之十**（723 / 956）。
