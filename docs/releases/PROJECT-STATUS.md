| macOS 13+ (Apple Silicon) | **DEV-08 批次 13 项原生验收通过**；**当前 release 产物的运行验收尚未完成** | QA 包原生窗口走查：八页渲染、订单详情、附件 4/4、备份面板、附件维护、关于页、重启后数据保持；资产协议 12 条 URL（开发 + 打包各一轮）；双环境重置与隔离 |

**两处必须区分的口径**：

1. macOS 的 PASS 属于 **DEV-08 构建**。Release `v0.1.0-demo.2` 里的 macOS zip/dmg 由后续重新打包，只做了体积、SHA-256、Identifier 与 ad-hoc 签名的静态复核——不能把 DEV-08 的结论直接算在这批产物上。
2. Windows 的 56 项来自真机执行，其中原始第二阶段报告本身判 **PARTIAL**（理由是约三分之一目标项未完成或受阻）。「核心功能基本通过」说的是功能可用性，「PARTIAL」说的是测试完备度，两者同时成立。
