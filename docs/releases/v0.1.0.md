## 安装

- macOS：解压 → 拖进应用程序 → **右键 → 打开**（未公证）。
- Windows：双击安装；缺 WebView2 时会引导下载。

## 两个版本的区别

| | Production | QA |
| --- | --- | --- |
| Identifier | `dev.artflow.minidesk` | `dev.artflow.minidesk.qa` |
| 数据目录 | 正式目录 | QA 目录（seeded / clean 两个场景） |
| 建议 | 自己的真实委托 | 先试玩、演示 |

QA 在 Windows 上默认进入 seeded（演示数据）；要空白环境用交付包里的 `启动 QA Clean（空白环境）.cmd`。
