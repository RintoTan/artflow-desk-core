# Windows 使用手册

面向使用 ArtFlow Desk Core 的画师，不需要任何开发知识，也不需要命令行。

> **状态说明**：本版本由 GitHub Actions 在 Windows 上构建，并通过了自动化的「启动 → 关窗 → 进程退出 → 二次启动」冒烟测试。
> **但还没有在任何一台真实的 Windows 电脑上做过安装、卸载、缩放、中文路径的手动验证。**
> 如果你在操作中发现与手册不一致的地方，请记录并反馈（见第 10 节）。

## 1. 两个版本、四个文件

同一份代码，两种身份：

| | 正式版（Production） | QA 版 |
| --- | --- | --- |
| 用途 | 记录你自己的真实委托 | 试玩、演示、走流程 |
| 窗口标题 | ArtFlow Desk Core | ArtFlow Desk Core — QA 测试环境 |
| 数据目录 | `%APPDATA%\dev.artflow.minidesk` | `%APPDATA%\dev.artflow.minidesk.qa\<场景>` |
| 首次打开 | 空白台账 | 有十几条演示订单（seeded 场景） |

每种版本都有两个文件：

| 文件 | 说明 |
| --- | --- |
| `...-Production-Setup.exe` / `...-QA-Setup.exe` | 安装程序（NSIS），装到系统里，有开始菜单图标 |
| `...-Production-Portable.exe` / `...-QA-Portable.exe` | 免安装，双击就能跑，可以放在 U 盘或任意文件夹 |

**两者数据位置完全一样**（都在 `%APPDATA%`），区别只是「要不要安装」。
不要用 Portable 版当「便携数据」——把 exe 拷到别的电脑，数据不会跟着走；换电脑请用「备份 / 恢复」。

> 正式版和 QA 版的数据互相隔离。第一次使用建议先用 **QA 版** 试，熟悉后再用正式版记录真实委托。

## 2. 安装正式版

1. 下载 `ArtFlowDesk-Core-Windows-v0.1.0-Production-Setup.exe` 和 `SHA256SUMS.txt`。
2. （可选，建议）校验文件：把两个文件放在同一个文件夹，右键「在终端中打开」，输入
   `Get-FileHash .\*Production-Setup.exe -Algorithm SHA256`，与 `SHA256SUMS.txt` 里那行比对。
3. 双击安装包。默认装到当前用户目录，不需要管理员权限。
4. 若出现「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。当前版本没有购买代码签名证书，这条提示是预期的。
5. 安装完成后从开始菜单启动 `ArtFlow Desk Core`。

## 3. 安装 QA 版

与正式版完全相同的步骤，只是换成 `...-QA-Setup.exe`，开始菜单里叫 `ArtFlow Desk Core QA`。
两者可以同时安装、同时运行，数据互不影响。

## 4. 直接使用便携版（不安装）

1. 下载 `ArtFlowDesk-Core-Windows-v0.1.0-QA-Portable.exe`（或 Production 版）。
2. 放到一个**你自己有写权限**的文件夹（不要放在 `C:\Program Files` 下）。
3. 双击运行。首次运行同样会有 SmartScreen 提示，处理方式同上。

便携版不会创建开始菜单图标，也不会写注册表；删除 exe 就算「移除程序」，但 `%APPDATA%` 里的数据仍然保留。

> **运行前提**：需要系统已安装 Microsoft Edge WebView2 Runtime。Windows 11 与更新过的 Windows 10 一般自带；
> 若出现「缺少 WebView2」提示，按提示安装 `Microsoft Edge WebView2 Runtime` 后重试。

## 5. 启动 QA Clean 空白环境

QA 版默认进入 **seeded**（演示数据）场景。想体验「刚装好、一条数据都没有」的状态，用 clean 场景：

- **装的是安装版**：双击交付包里的 `启动 QA Clean（空白环境）.cmd`。
- **用的是便携版**：把 `启动 QA Clean（Portable 便携版）.cmd` 和便携版 exe 放在同一个文件夹，双击脚本。

这两个脚本只对「这一次启动」生效，不修改你的系统环境变量，也不需要任何开发工具。
clean 与 seeded 的数据分别存放在两个目录，互不覆盖。

## 6. 第一次打开

正式版首次启动应看到：

- 工作台所有统计为 **0**，时间线写「尚无订单」；
- 订单、客户为空；
- 流程模板里已有一个「通用制作流程」。

如果第一次打开就看到一堆订单，说明你打开的是 QA 版。

## 7. 正常退出与重新打开

- **退出**：点窗口右上角 `×`，或按 `Alt + F4`。
  如果当时有未保存的编辑，会先弹出确认框：可以「保存并关闭」「放弃修改」或「取消」。
  关闭后进程会立即退出，任务管理器里不留残余。
- **重新打开**：再点一次开始菜单图标 / 双击 exe 即可，不需要重启电脑，也不需要手工清理。
- **同时开两个**：不需要，也不建议。若第一个窗口还在运行，再次双击会提示「已有一个实例在运行」。
- **确认真的退出了**：任务管理器（`Ctrl + Shift + Esc`）→「详细信息」里搜索 `artflow-minidesk`，正常关闭后不应有残留。
  若确实残留，先不要强杀，按第 10 节收集日志再反馈。

## 8. 日常使用

### 建客户与订单

1. 左侧「订单」→ 右上「新建」。
2. 填标题；客户栏可直接输入新客户名（会一并创建）。
3. 填计划开始 / 交付日期，日历里就会出现这条订单。

### 推进制作

订单详情 →「推进阶段」。可以返工、可以跳级（跳级需要填写原因与保留的阶段快照）。

### 日历、统计

- 日历支持月 / 周视图，拖动订单条即可改期，改期会写入历史。
- 统计页按月份看完成与收入，可按当前筛选导出 CSV。

### 附件

订单详情 →「附件」。支持多选导入与拖拽导入；导入后会生成缩略图，点开可看原图。

### 备份

设置 →「数据备份」→「创建备份」。备份是一个 ZIP，包含数据库快照、附件和校验清单。
换电脑时：把 ZIP 拷到新机器 → 安装同版本 → 「恢复备份」。

## 9. 数据在哪、如何查看版本

```
%APPDATA%\dev.artflow.minidesk              ← 正式版
%APPDATA%\dev.artflow.minidesk.qa\seeded    ← QA 演示数据
%APPDATA%\dev.artflow.minidesk.qa\clean     ← QA 空白环境
%APPDATA%\dev.artflow.minidesk\logs\app.log        ← 正式版诊断日志
%APPDATA%\dev.artflow.minidesk.qa\logs\app.log     ← QA 版诊断日志（clean / seeded 共用）
```

在资源管理器地址栏粘贴 `%APPDATA%` 回车即可打开。
应用内「关于软件 → 数据环境」也能看到当前版本号与具体数据路径。

## 10. 出问题时怎么收集信息

先看日志，再反馈。日志在 `%APPDATA%\<版本对应的标识目录>\logs\app.log`（正式版是 `dev.artflow.minidesk`，QA 版是 `dev.artflow.minidesk.qa`，两个场景共用），
里面只有「启动 / 窗口 / 退出 / 错误」事件，不含客户与订单内容。

| 现象 | 先做什么 |
| --- | --- |
| 双击没反应 / 被 SmartScreen 拦 | 点「更多信息」→「仍要运行」；仍无反应看下一条 |
| 提示「已有一个实例在运行」 | 说明确实还有窗口在跑；切到任务栏找一下，或按第 7 节确认进程 |
| 打开后白屏 | 装 / 更新 WebView2 运行时后重试；仍白屏请附 `app.log` |
| 窗口关了但任务管理器还有进程 | 记录进程名与 PID，复制 `app.log` 全文，反馈给我们 |
| 中文路径的图片导入失败 | 换到英文路径试一次，把两次结果一起反馈 |
| 界面在高 DPI 下发虚或重叠 | 记录缩放比例（125% / 150% / 200%）并截图 |
| 恢复备份报校验失败 | 备份包可能损坏或被改动，换一份备份再试 |

反馈时请附：Windows 版本、应用版本（关于软件页）、现象描述、`app.log` 全文、必要截图。

## 11. 卸载

`设置 → 应用 → 已安装的应用 → ArtFlow Desk Core（或 QA）→ 卸载`。

- 卸载只移除程序文件，**不会删除** `%APPDATA%` 下的数据目录；重装后数据仍在。
- 如果确定不再需要这些数据，卸载后手动删除对应目录即可（删除前建议先做一份备份）。
- 便携版没有安装过程，删除 exe 即可；数据目录同样保留。
