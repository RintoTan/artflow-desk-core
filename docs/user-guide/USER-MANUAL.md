# ArtFlow Desk Core 用户手册

面向使用 ArtFlow Desk Core 的画师。不需要懂数据库、终端或编程。

- macOS 分册：[USER-MANUAL-macOS.md](USER-MANUAL-macOS.md)
- Windows 分册：[USER-MANUAL-Windows.md](USER-MANUAL-Windows.md)

---

## 1. 安装

### macOS
1. 下载 `ArtFlowDesk-Core-macOS-v0.1.0-QA.zip`（推荐先试 QA 版）或 Production 版。
2. 解压后把 App 拖进「应用程序」。
3. 首次打开：**右键 → 打开**（当前未做 Apple 公证，直接双击会被拦一次）。
4. 正常退出：`⌘Q` 或关闭窗口。

### Windows
1. 下载 `...-Setup.exe`，双击安装；SmartScreen 提示 → 「更多信息」→「仍要运行」。
2. 安装程序会检查 WebView2 运行时，缺失时引导联网安装。
3. 从开始菜单启动；卸载在「设置 → 应用」里。

> 当前未做代码签名，两端的首次运行提示都是正常的。

## 2. 第一次使用

1. **设置工作时区**：日期与「今天」都按它计算，换电脑后建议先确认一次。
2. **看流程模板**：默认已有「通用制作流程」（5 个阶段），可按习惯改。
3. **认识工作台**：订单计数、到期提醒、本月完成次数、跨订单时间线。
4. **找到备份入口**：设置 → 数据备份，之后每次大改前建议导一份。

## 3. 订单

- **新建**：订单页右上「新建」，标题必填，客户可直接输入新名字一并创建，日期可后补。
- **编辑**：详情左侧「资料」，改完「保存资料」。
- **复制 / 取消 / 完成 / 重新打开**：详情顶部按钮，危险操作会二次确认。
- **视图**：卡片 / 看板 / 表格，可搜索标题、编号、客户、来源，按流程与阶段筛选。
- **编号**：`AF-2026-0001` 形式，先预留后创建，允许空号，不会因为取消而复用。

## 4. 客户

新建、改名、打标签；订单关联客户后，客户详情能看到该客户的全部委托。
被订单引用的客户不能删除。

## 5. 制作流程

- 模板是「模板」，订单里是「副本」：下单时生成，之后互不影响。
- **推进**：一次一级。
- **返工**：退回任意更早阶段重做。
- **跳级**：客户只要成图时可跳过中间阶段；被跳过的阶段标「已跳过」，**不算完成**。
- 所有变化进「制作历史」，含时间、阶段快照与原因。

## 6. 日历与排期

- 月视图看整月，周视图看细节，都能连续前后滚动。
- 订单按「计划开始 → 计划交付」绘制；颜色只表示排期状态。
- 拖动订单条到别的日期即可改期，确认后写入排期历史。
- 计划日期是排期，实际时间在制作历史里，两者不互相覆盖。

## 7. 附件

- 订单详情「参考图片」→「添加图片」多选，或把图片拖进该区域。
- 部分文件失败会逐个说明原因，成功的照常导入。
- 点缩略图看大图，可缩放平移；缩略图可重建，**原图丢了只能靠备份**。
- 参考图只属于该订单，不会进入任何作品集。
- 设置 →「附件维护」可查看隔离文件与导入记录，只在你确认后清理。

## 8. 统计

按月看完成数与收入，客户/模板可下钻；右上「导出」把当前筛选结果导成 CSV，Excel 直接打开。

## 9. 备份与恢复

**备份**：设置 → 数据备份 →「导出备份…」→ 选位置保存 `.zip`。
包含完整数据库 + 全部附件原图；**未加密**，内含客户信息。

**恢复**：「从备份恢复…」→ 选包 → 看摘要与兼容性 → 确认。
恢复前会自动备份当前数据；失败不会破坏现有数据；完成后需重启应用。

**换电脑**：新机装好 → 打开一次 → 用「从备份恢复」导入。

## 10. 快捷键

| 键（macOS / Windows） | 功能 | 范围 |
| --- | --- | --- |
| ⌘N / Ctrl+N | 新建 | 订单、客户、流程模板 |
| ⌘S / Ctrl+S | 保存修改 | 详情、客户、模板、设置 |
| ⌘F / Ctrl+F | 聚焦搜索 | 订单 |
| ↑ / ↓ | 移动选择 | 订单 |
| Enter | 打开选中订单 | 订单 |
| Esc | 关闭最上层弹窗 | 全局 |

## 11. 常见问题

| 现象 | 处理 |
| --- | --- |
| 打不开、提示未验证开发者 | 右键 → 打开；或隐私与安全性里「仍要打开」 |
| 打开后白屏（Windows） | 安装/更新 WebView2 运行时 |
| 图片显示不出来 | 检查原图是否还在，点「重建缩略图」 |
| 恢复报校验失败 | 备份包损坏，换一份更早的 |
| 想确认数据还在 | 「关于软件 → 数据环境」看订单/客户/附件数量 |
| 想反馈问题 | 附截图 + 操作步骤 + 系统版本 |

## 12. 数据在哪

| 平台 | 路径 |
| --- | --- |
| macOS | `~/Library/Application Support/dev.artflow.minidesk` |
| Windows | `%APPDATA%\dev.artflow.minidesk` |

卸载不会自动删除数据目录（以实机表现为准，卸载前建议先备份）。

## 13. 两个版本怎么选

| | Production | QA |
| --- | --- | --- |
| 用途 | 真实委托 | 试用、演示 |
| 数据 | 独立目录 | 独立目录，默认演示数据 |
| 建议 | 熟练后再用 | **第一次先玩这个** |
