# ArtFlow Desk Core 使用手册

面向使用 ArtFlow Desk Core 的画师。不需要开发知识，也不需要命令行。
两个平台的操作基本一致，差异集中在「安装」和「数据在哪」两节，其余通用。

## 1. 两个版本

同一份代码，两种身份：

| | 正式版（Production） | QA 版 |
| --- | --- | --- |
| 用途 | 记录你自己的真实委托 | 试玩、演示、走流程 |
| 窗口标题 | ArtFlow Desk Core | ArtFlow Desk Core — QA 测试环境 |
| 数据目录 | `dev.artflow.minidesk` | `dev.artflow.minidesk.qa/<场景>` |
| 首次打开 | 空白台账 | 十几条演示订单（seeded 场景） |

两者**数据完全隔离**，可以同时安装、同时运行。第一次用建议先点 QA 版，熟悉后再用正式版记真实委托。

## 2. 安装与首次打开

### macOS

**系统要求**：macOS 13.0 或更新，Apple Silicon（M 系列）。

1. 从 Releases 下载 `.dmg`（或 `.zip`）。
2. 双击打开 DMG，把 **ArtFlow Desk Core** 拖进「应用程序」，然后弹出磁盘映像。
3. **首次打开需要手动放行一次**（当前版本没有 Apple Developer ID 签名与公证）：
   - 方法 A：在「应用程序」里 **右键 → 打开**，弹窗里再点「打开」；
   - 方法 B：双击被拦后，去 `系统设置 → 隐私与安全性`，页面底部点「仍要打开」。
4. 之后正常双击即可，不会再提示。

### Windows

**系统要求**：Windows 10 1809+ 或 Windows 11（x64）；需要系统已安装 Microsoft Edge WebView2 Runtime（Win11 与更新过的 Win10 一般自带）。

每个版本有两个文件：

| 文件 | 说明 |
| --- | --- |
| `...-Production-Setup.exe` / `...-QA-Setup.exe` | 安装程序（NSIS），装到系统里，有开始菜单图标 |
| `...-Production-Portable.exe` / `...-QA-Portable.exe` | 免安装，双击即跑，可放在任意有写权限的文件夹 |

**两者数据位置完全一样**（都在 `%APPDATA%`），区别只是「要不要安装」。不要把 Portable 版当「便携数据」——把 exe 拷到别的电脑，数据不会跟着走；换电脑请用备份/恢复。

安装步骤：

1. 下载 `...-Production-Setup.exe` 和 `SHA256SUMS.txt`（可选校验：`Get-FileHash .\*Production-Setup.exe -Algorithm SHA256` 后比对）。
2. 双击安装，默认装到当前用户目录，**不需要管理员权限**。
3. 若出现「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。当前版本没有购买代码签名证书，这条提示是预期的。
4. 从开始菜单启动。

便携版：放到自己有写权限的文件夹（不要放 `C:\Program Files`），双击运行；同样会有 SmartScreen 提示。不创建开始菜单图标，不写注册表。

#### QA Clean 空白环境

QA 版默认进 seeded（演示数据）。想看「刚装好、一条数据都没有」：

- 安装版：双击交付包里的 `启动 QA Clean（空白环境）.cmd`；
- 便携版：把 `启动 QA Clean（Portable 便携版）.cmd` 和 exe 放同一文件夹，双击脚本。

只对这一次启动生效，不改系统环境变量。clean 与 seeded 的数据分目录存放，互不覆盖。

### 第一次打开应该看到什么

- 工作台所有统计为 **0**，时间线写「尚无订单」；
- 订单、客户为空；
- 流程模板里已有一个「通用制作流程」。

如果一打开就看到一堆订单，说明你打开的是 QA 版。

## 3. 日常使用

### 建客户与订单

1. 左侧「订单」→ 右上「新建」。
2. 填标题；客户栏可直接输入新客户名（会一并创建）。
3. 填计划开始 / 计划交付日期（可以之后再补）。
4. 保存。编号自动分配（`AF-2026-0001` 这种形式）。

### 推进制作

1. 打开订单，点 **开始制作**。
2. 每完成一个阶段，点 **推进阶段…** → 选下一阶段 → 确认。
3. 客户中途要改、需要退回重画：同一入口里选 **返工**，可退回任意更早阶段。
4. 中间阶段不需要做（比如客户只要成图）：选 **跳级**，被跳过的阶段标记「已跳过」，但**不会**算成已完成。
5. 全部完成点 **完成**；不做了点 **取消订单**（二次确认）。

所有动作都会写进右侧「制作历史」，包括时间、阶段变化和原因。

### 日历与改期

- 「日历」里按月或按周看排期，可以一直往前/往后滚。
- 拖动订单条到别的日期，会弹出改期确认，确认后写入排期历史。
- 计划日期是你自己排的；实际开始与完成时间记在制作历史里，两者不会互相覆盖。

### 统计

「历史统计」按月看完成数与收入，点客户/模板可下钻。右上「导出」把当前筛选的订单导成 CSV，Excel 能直接打开。

### 正常退出

- macOS：`⌘ Q` 或关窗。
- Windows：点 `×` 或 `Alt + F4`。
- 有未保存编辑时会先确认（保存并关闭 / 放弃修改 / 取消）。关闭后进程立即退出，任务管理器里不留残余。
- 同一数据目录只允许一个实例：已有窗口在跑时再双击，会提示「已有一个实例在运行」后退出。

## 4. 附件与参考图

- 订单详情里「参考图片」→ **添加图片**（可多选），或把图片直接拖进这个区域。
- 部分文件失败时会逐个说明原因，成功的照常导入。
- 点缩略图看大图，可缩放、拖动。
- 缩略图丢了可以点「重建缩略图」；**原图丢了没法自动恢复**，所以备份很重要。
- 参考图只属于这个订单，不会进任何作品集或公开页面。

## 5. 备份与换电脑

**手动备份**（没有自动定时备份）：

1. `设置 → 数据备份 → 导出备份…`
2. 选一个找得到的位置（建议外置硬盘或网盘同步目录）。
3. 得到 `.zip`，里面是完整数据库 + 全部附件原图，可整体搬到另一台电脑。

**恢复**：

1. `设置 → 数据备份 → 从备份恢复…`，选那个 `.zip`。
2. 先显示包里的内容（时间、版本、订单/客户/附件数量）和兼容性。
3. 确认后开始；恢复前会**自动**再备份一次当前数据。
4. 完成后按提示重启应用（重启前读不到新数据是正常的）。

恢复失败不会破坏现有数据——它会拒绝切换，保留当前数据。

> 备份包**没有加密**，里面有客户姓名和金额，别随手发给别人。

**换电脑**：新机器装好应用 → 打开一次让它建好数据目录 → 用「从备份恢复」导入旧备份。恢复后编号不会退回到旧值（可能产生空号）。

## 6. 快捷键

macOS 用 ⌘，Windows 用 Ctrl，映射一致：

| 快捷键 | 功能 | 在哪些页面 |
| --- | --- | --- |
| ⌘/Ctrl + N | 新建 | 订单、客户、流程模板 |
| ⌘/Ctrl + S | 保存当前修改 | 订单详情、客户、流程模板、设置 |
| ⌘/Ctrl + F | 光标进入搜索框 | 订单 |
| ↑ / ↓ | 移动选中的订单 | 订单 |
| Enter | 打开选中的订单 | 订单 |
| Esc | 关闭最上面一层弹窗 | 全局 |

- 方向键只移动选择，不改动队列顺序；
- 没有改动时 ⌘/Ctrl + S 不会保存任何东西；
- 光标在输入框里时，方向键和 Enter 只管打字。

## 7. 数据在哪

```
macOS
~/Library/Application Support/dev.artflow.minidesk            ← 正式版
~/Library/Application Support/dev.artflow.minidesk.qa         ← QA 版（内含 seeded / clean）

Windows
%APPDATA%\dev.artflow.minidesk                                ← 正式版
%APPDATA%\dev.artflow.minidesk.qa\seeded                      ← QA 演示数据
%APPDATA%\dev.artflow.minidesk.qa\clean                       ← QA 空白环境
%APPDATA%\dev.artflow.minidesk\logs\app.log                   ← 正式版诊断日志
%APPDATA%\dev.artflow.minidesk.qa\logs\app.log                ← QA 日志（clean / seeded 共用）
```

Windows 在资源管理器地址栏粘贴 `%APPDATA%` 回车即可打开。
应用内「关于软件 → 数据环境」能看到当前版本号与具体数据路径。

## 8. 出问题时

**先看日志**：`<数据根>/logs/app.log`。里面只有「启动 / 窗口 / 退出 / 错误」事件，不含客户与订单内容。

| 现象 | 先做什么 |
| --- | --- |
| macOS：双击打不开、提示「无法验证开发者」 | 右键 → 打开；或去隐私与安全性点「仍要打开」 |
| Windows：双击没反应 / 被 SmartScreen 拦 | 点「更多信息」→「仍要运行」；仍无反应看下一条 |
| 提示「已有一个实例在运行」 | 确实还有窗口在跑；切到任务栏找一下，或确认进程 |
| 打开后白屏 | Windows 装/更新 WebView2 后重试；仍白屏请附 `app.log` |
| 窗口关了但任务管理器还有进程 | 记录进程名与 PID，复制 `app.log` 全文，反馈给我们 |
| 中文路径的图片导入失败 | 换到英文路径再试一次，把两次结果一起反馈 |
| 界面在高 DPI 下发虚或重叠 | 记录缩放比例（125% / 150% / 200%）并截图 |
| 图片显示不出来 | 看订单里原图是否还在；点「重建缩略图」；确认没手动删过 `attachments` |
| 恢复备份报校验失败 | 备份包可能损坏或被改动，换一份备份再试 |
| 升级后不确定数据还在 | 「关于软件 → 数据环境」看订单/客户/附件数量，再导一份备份做保险 |

反馈时请附：系统版本、应用版本（关于软件页）、现象描述、`app.log` 全文、必要截图。

## 9. 卸载

**macOS**：把应用拖进废纸篓。按当前实现，卸载**不会**删除数据目录（卸载前建议先备份）。

**Windows**：`设置 → 应用 → 已安装的应用 → ArtFlow Desk Core（或 QA）→ 卸载`。

- 卸载只移除程序文件，**不会删除** `%APPDATA%` 下的数据；重装后数据仍在。
- 确定不再需要时，卸载后手动删除对应目录（删除前先做一份备份）。
- 便携版没有安装过程，删除 exe 即可；数据目录同样保留。
