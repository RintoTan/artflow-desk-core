## 1. 安装

**系统要求**：Windows 10（1809 及以上）或 Windows 11，**64 位**。

1. 从 Releases 下载 `ArtFlow Desk Core_0.1.0_x64-setup.exe`（正式版）或 QA 版安装包。
2. 双击运行。若出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」——当前版本未做代码签名，这是正常提示。
3. 按向导完成安装，可以勾选「立即运行」。

**关于 WebView2**：应用界面依赖微软的 WebView2 运行时。多数 Windows 10/11 已自带；如果安装时提示缺失，安装程序会引导联网下载（`Microsoft Edge WebView2 Runtime`）。装好后重新运行应用即可。

## 2. 第一次打开

首次启动应看到：

- 工作台所有统计为 **0**，时间线写「尚无订单」；
- 订单、客户为空；
- 流程模板里已有一个「通用制作流程」。

如果第一次打开就看到一堆订单，说明你打开的是 QA 版（演示数据），不是正式版。

## 3. 两个版本、三个入口

| 入口 | 怎么打开 | 看到什么 | 数据位置 |
| --- | --- | --- | --- |
| 正式版 | 开始菜单 `ArtFlow Desk Core` | 你自己的数据 | `%APPDATA%\dev.artflow.minidesk` |
| QA 版 · 演示数据 | 开始菜单 `ArtFlow Desk Core QA` | 十几条演示订单 | `%APPDATA%\dev.artflow.minidesk.qa\seeded` |
| QA 版 · 空白环境 | 双击交付包里 `Launchers\启动 QA Clean（空白环境）.cmd` | 像刚安装一样干净 | `%APPDATA%\dev.artflow.minidesk.qa\clean` |

- 三个位置的数据互不影响；在 QA 里怎么改都不会动正式版。
- 想体验「新装软件」的感觉，用第三个入口。
- 启动脚本只对那一次启动生效，不会改你的系统环境变量，也不需要装任何开发工具。
- 若脚本提示找不到程序：说明 QA 版装在了非默认目录，右键编辑脚本里的路径即可。

## 4. 日常使用

### 建客户与订单

1. 左侧「订单」→ 右上「新建」。
2. 填标题；客户栏可直接输入新客户名（会一并创建）。
3. 填计划开始 / 计划交付日期。
4. 保存，编号自动分配（`AF-2026-0001`）。

### 推进制作

- **开始制作** → 之后每完成一个阶段点 **推进阶段…**。
- **返工**：退回更早阶段重做。
- **跳级**：中间阶段不需要做时用，被跳过的阶段标记「已跳过」，不算完成。
- **完成 / 取消订单**：都在详情顶部。

### 日历、统计

- 日历支持月/周视图，拖动订单条即可改期。
- 统计里可按月看完成与收入，能导出 CSV（Excel 打开）。

## 5. 附件与参考图

- 订单详情「参考图片」→ **添加图片**（可多选），或把文件从资源管理器拖进来。
- 支持中文文件名与含空格的路径（**这一条尚未在 Windows 实机验证**）。
- 点缩略图看大图，可缩放拖动。
- 参考图只属于该订单，不会进任何作品集。

## 6. 备份与换电脑

**备份**：`设置 → 数据备份 → 导出备份…`，选位置保存 `.zip`。备份包含完整数据库与全部附件原图。

**恢复**：`从备份恢复…` → 选文件 → 看摘要与兼容性 → 确认。恢复前会自动把当前数据再备份一份；失败不会破坏现有数据。

备份包**未加密**，含客户信息与金额，注意保管。

换电脑：新机器装好 → 打开一次 → 用「从备份恢复」导入。**macOS 与 Windows 之间的备份互恢复尚未验证**，暂时建议同平台迁移。

## 7. 快捷键

| 快捷键 | 功能 | 在哪些页面 |
| --- | --- | --- |
| Ctrl + N | 新建 | 订单、客户、流程模板 |
| Ctrl + S | 保存当前修改 | 订单详情、客户、流程模板、设置 |
| Ctrl + F | 光标进入搜索框 | 订单 |
| ↑ / ↓ | 移动选中的订单 | 订单 |
| Enter | 打开选中的订单 | 订单 |
| Esc | 关闭最上面一层弹窗 | 全局 |

## 8. 数据在哪

```
%APPDATA%\dev.artflow.minidesk          ← 正式版
%APPDATA%\dev.artflow.minidesk.qa\seeded ← 演示数据
%APPDATA%\dev.artflow.minidesk.qa\clean  ← 空白环境
```

在地址栏粘贴 `%APPDATA%` 回车即可打开。应用内「关于软件 → 数据环境」也能看到具体路径。

**卸载**：`设置 → 应用 → 已安装的应用 → ArtFlow Desk Core → 卸载`。按当前实现，卸载只移除程序，**不删除** `%APPDATA%` 下的数据目录（这一条需在你机器上确认；卸载前建议先备份）。

## 9. 出问题时

| 现象 | 先做什么 |
| --- | --- |
| 双击没反应 / 被 SmartScreen 拦 | 「更多信息」→「仍要运行」 |
| 打开后白屏 | 装/更新 WebView2 运行时后重试 |
| 中文路径的图片导入失败 | 换到英文路径试一次，把结果反馈给我们 |
| 界面在高 DPI 下发虚 | 记录缩放比例（125%/150%）与截图 |
| 恢复备份报校验失败 | 备份包可能损坏，换一份 |
| 数据看着不对 | 「关于软件」看订单/客户/附件数量，先导出备份再排查 |
