## 1. 安装

**系统要求**：macOS 13.0 或更新；Apple Silicon（M 系列）。

1. 从 Releases 下载 macOS 的 `.dmg`（或 `.zip`）。
2. 双击打开 DMG，把 **ArtFlow Desk Core** 拖进「应用程序」文件夹。
3. 弹出磁盘映像。

> 当前版本没有 Apple Developer ID 签名与公证，第一次打开会提示「无法验证开发者」。

## 2. 第一次打开

因为未签名，需要一次手动放行：

- **方法 A**：在「应用程序」里 **右键 → 打开**，在弹窗里再点「打开」。
- **方法 B**：双击后如果被拦，去 `系统设置 → 隐私与安全性`，页面底部点「仍要打开」。

之后正常双击即可，不会再提示。

首次打开你会看到：

- 工作台全部数字为 **0**，时间线写「尚无订单」；
- 订单、客户都是空的；
- 流程模板里已经有一个「通用制作流程」（5 个阶段）。

**两个版本怎么选**：

| 版本 | 用什么数据 | 什么时候用 |
| --- | --- | --- |
| ArtFlow Desk Core（正式版） | 你自己的真实委托 | 日常干活 |
| ArtFlow Desk Core QA（演示版） | 演示数据，与正式版完全隔离 | 先随便点、看界面、试功能 |

演示版里删东西、改日期都不会影响正式版。

## 3. 日常使用

### 建客户与订单

1. 左侧「订单」→ 右上「新建」。
2. 填标题；客户栏可以直接输入新客户名（会一并创建）。
3. 填计划开始 / 计划交付日期（可以之后再补）。
4. 保存。编号自动分配（`AF-2026-0001` 这种形式）。

### 推进制作

1. 打开订单，点 **开始制作**。
2. 每完成一个阶段，点 **推进阶段…** → 选下一阶段 → 确认。
3. 客户中途要改、需要退回重画：同一个入口里选 **返工**，可以退回任意更早阶段。
4. 中间阶段不需要做（比如客户只要成图）：选 **跳级**，被跳过的阶段会标记「已跳过」，但**不会**算成已完成。
5. 全部完成点 **完成**；不做了点 **取消订单**（会二次确认）。

所有动作都会写进右侧「制作历史」，包括时间、阶段变化和原因。

### 日历与改期

- 「日历」里按月或按周看排期；可以一直往前或往后滚。
- 拖动订单条到别的日期，会弹出改期确认，确认后写入排期历史。
- 计划日期是你自己排的；实际开始和完成时间记录在制作历史里，两者不会互相覆盖。

### 统计

「历史统计」按月看完成数与收入，点客户/模板可以下钻。右上「导出」把当前筛选的订单导成 CSV，Excel 能直接打开。

## 4. 附件与参考图

- 订单详情里「参考图片」→ **添加图片**（可多选），或把图片直接拖进这个区域。
- 部分文件失败时会逐个说明原因，成功的照常导入。
- 点缩略图看大图，可缩放、拖动。
- 缩略图丢了可以点「重建缩略图」；原图丢了没法自动恢复，所以**备份很重要**。
- 参考图只属于这个订单，不会进任何作品集或公开页面。

## 5. 备份与换电脑

**手动备份**（没有自动定时备份）：

1. `设置 → 数据备份 → 导出备份…`
2. 选一个你找得到的位置（建议外置硬盘或网盘同步目录）。
3. 得到 `.zip`。

备份包里是完整数据库 + 全部附件原图，可以整体搬到另一台电脑。

**恢复**：

1. `设置 → 数据备份 → 从备份恢复…`，选那个 `.zip`。
2. 会先显示包里的内容（时间、版本、订单/客户/附件数量）和兼容性。
3. 确认后开始恢复；恢复前会**自动**再备份一次当前数据。
4. 完成后按提示重启应用。

恢复失败不会破坏现有数据——它会拒绝切换，并保留当前数据。

> 备份包**没有加密**，里面有客户姓名和金额，别随手发给别人。

**换电脑**：在新电脑装好应用 → 打开一次让它建好数据目录 → 用「从备份恢复」导入旧备份。

## 6. 快捷键

| 快捷键 | 功能 | 在哪些页面 |
| --- | --- | --- |
| ⌘ N | 新建 | 订单、客户、流程模板 |
| ⌘ S | 保存当前修改 | 订单详情、客户、流程模板、设置 |
| ⌘ F | 光标进入搜索框 | 订单 |
| ↑ / ↓ | 移动选中的订单 | 订单 |
| Enter | 打开选中的订单 | 订单 |
| Esc | 关闭最上面一层弹窗 | 全局 |

- 方向键只移动选择，不会改动队列顺序；
- ⌘ S 在没有改动时不会保存任何东西；
- 光标在输入框里时，方向键和 Enter 只管打字。

## 7. 数据在哪

```
~/Library/Application Support/dev.artflow.minidesk      ← 正式版
~/Library/Application Support/dev.artflow.minidesk.qa   ← 演示版（内含 seeded / clean 两个场景）
```

「关于软件」页里能直接看到当前用的目录、数据库版本和数据代际。

**卸载**：把应用拖进废纸篓即可。按当前实现，卸载**不会**删除上面那两个数据目录（这一条以你机器上的实际表现为准，卸载前建议先做一次备份）。

## 8. 出问题时

| 现象 | 先做什么 |
| --- | --- |
| 双击打不开、提示「无法验证开发者」 | 右键 → 打开；或去隐私与安全性里点「仍要打开」 |
| 打开后一片空白 / 报「无法读取数据环境」 | 关掉应用重开；仍不行就检查数据目录是否存在、磁盘是否满 |
| 图片显示不出来 | 看订单里原图是否还在；点「重建缩略图」；确认没有手动删过 `attachments` 目录 |
| 恢复备份时提示校验失败 | 备份包可能损坏或被改过；换一份更早的备份 |
| 升级后不确定数据还在 | 打开「关于软件 → 数据环境」看订单/客户/附件数量；再用「导出备份」导一份做保险 |

实在解决不了：把「关于软件」页截图 + 问题描述发到仓库 Issues。
