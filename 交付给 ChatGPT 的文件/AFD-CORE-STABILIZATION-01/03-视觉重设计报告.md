# 视觉重设计（Batch B）

## UX-08 客户页

- 详情根沿用 `.orders-detail`（已是 `container-type: inline-size`），新增 `.client-columns`：详情容器 ≥720px 时 `1.55fr / 1fr`。
- 左列：客户资料（名称 / 联系方式 / 备注 + 保存、还原），联系方式沿用 200px 起的最小宽度，不被拉满整行。
- 右列：客户概览（订单数、已知金额、最近下单）与标签（含新建、移除、管理全部标签）。
- 下方面积给「关联订单」表格，保持整宽。
- 实测：1400px 窗口 → 详情 779px → 左 452 / 右 291（截图 `05-客户-1400.png`）；1680px → 左 600+（截图 `05-客户-1680.png`）。
- 单栏回退：详情 <720px（900px 窗口为 585px、1100px 为 479px）保持上下排列，没有横向滚动。
- 未改：同名不合并（ID 选择）、筛选、保存协议、未保存保护、标签数据与订单关联。

## UX-09 历史统计

整页结构改为四段：

1. **工具区** `.stats-toolbar`：`历史统计` 标题 + 口径说明（区间 · 时区 · 自然月 · 事件时间）+ 范围分段控件 + 导出汇总；一行内左右分布，不再挤在左上角。
2. **KPI** `.kpi-grid`：六项 `repeat(auto-fit, minmax(150px, 1fr))`，统一底色与内边距，24px 数字 + 12px 标签；只有"未知金额 > 0"保留警示色。
3. **趋势**：保留原柱状图与分排逻辑；新增 `data-single` —— 单月时柱子固定 88px 并居中，不再把一根柱拉满整幅图。
4. **月度明细**：字段与口径不变；数字列 `.num` 右对齐 + tabular-nums。

未改：数据源、创建/完成/取消计数、金额聚合、未知金额、时区、CSV 汇总结构、月份划分。

截图：`screenshots/03-统计-1400-改造前.png` 与 `screenshots/04-统计-1680.png`；900px 另有一张。

## SET-FIX-02 工作时区

- 新增 `src/lib/timezones.ts`：25 个常用时区（中文名 / 城市 / IANA）+ `offsetFor`（`Intl` 的 `longOffset`，夏令时按时刻计算）+ `searchZones`（中文、城市、IANA 皆可搜，`_`/`-` 归一为空格）+ `resolveZone`（先查表，再交给 `Intl` 校验）。
- 设置页原来的 `<datalist>` 换成 combobox：输入即过滤、上下键移动、Enter 选中、Esc 关闭；候选行显示「中国标准时间 · 上海 · UTC+08:00」。
- 输入非法值时 hint 变红字提示，且「保存设置」禁用（前端闸门）；后端仍会拒绝非法 IANA。
- 保存值仍是 IANA 名称，未改存储协议；没有新增"跟随系统"开关（现有协议只有固定 IANA，避免做无持久语义的假开关），如需该模式单独立项。
- 未改：主题、强调色、图标选择与预览、放弃修改、恢复默认主题确认。
