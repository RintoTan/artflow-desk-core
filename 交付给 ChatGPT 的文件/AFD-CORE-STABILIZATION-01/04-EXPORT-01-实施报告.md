# EXPORT-01 手动选择订单导出

## 交互

- 导出对话框新增第三个范围：`手动选择订单（已选 N 条）`，旁边是「选择订单…」。
- 打开选择器时先关闭导出框，避免两层模态叠加；确认/取消后回到导出框。
- 选择器：搜索（标题 / 编号 / 客户）、复选框、已选数量、清空选择、取消、确认（按钮文案「使用选中的 N 条」）。
- 搜索条件变化不清空已勾选：选中集合是 `string[]`，与渲染列表无关；跨阶段/来源都能选。
- 零选择时「导出 CSV」与「使用选中的 0 条」均禁用。

## 数据与隐私

- 只传勾选的订单 ID；后端沿用 `scope: "filtered"` + 显式 `order_ids`（后端本来就是这个语义），没有新增命令、没有改 CSV 字段白名单。
- 不依赖列表渲染顺序；不额外导出联系方式、备注、路径；UTF-8 与文件格式不变；仍走 macOS 保存对话框，取消不建文件。
- 已删除或不存在的 ID：后端按 `collect_orders` 现有规则处理（查不到的不会凭空造行）。

## 已知偏差

CSV 汇总行仍写「当前筛选结果（N 条）」而不是「手动选择（N 条）」，因为改动它需要动 Rust 的 label 逻辑，超出"不改 CSV 协议"的范围。字段与数据正确，只有这句元信息措辞不同。

## 验收用例（均已通过）

单个/多个指定订单、跨筛选选择、搜索后已选保留、清空选择、零选择禁用、取消保存不导出、原有两种范围不回归。
