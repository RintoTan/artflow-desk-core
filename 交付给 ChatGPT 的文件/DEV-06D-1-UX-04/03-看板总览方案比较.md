# 看板「总览」两方案比较

需求：总览必须能浏览**当前筛选下的全部订单**，不因切片遗漏；允许纵向滚动。

| | BOARD-A 纵向阶段分组 | BOARD-B 自适应阶段网格 |
|---|---|---|
| 900px | 每阶段一个横向分区，分区内 2 列卡片；一屏约 2 个阶段 | 自动换行成 2 列阶段；一屏可见 4 个阶段但卡片更窄 |
| 1400px | 分区仍是 2 列，过宽留白 | 3–4 列阶段，接近传统看板 |
| 全部订单可浏览 | 是（纵向滚动） | 是（纵向滚动） |
| 阶段顺序可读性 | 强（上下即先后） | 中（换行后需按 Z 字读） |
| 卡片可读性 | 强（卡片宽度大） | 中（窄列下标题更早截断） |
| 实现成本 | 中（分区容器 + 卡片两列） | 低（只改 flex-wrap） |

**推荐**：BOARD-A 用于 900px，BOARD-B 用于 ≥1400px（同一组件按容器宽度切换），
聚焦模式保留为子模式。

**待用户裁定**：是否接受"窄窗纵向分组 / 宽屏网格"的混合，还是全程只用一种。
