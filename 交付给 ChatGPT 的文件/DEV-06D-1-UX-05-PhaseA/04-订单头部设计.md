# 订单头部新设计（HEAD-NEW）

## 结构

- **主栏**：标题 + 数量 ｜ 视图切换 ｜ 新建（主按钮）。四项常驻，位置固定。
- **工具栏**：搜索（`flex 0 1 340px`，有上限）｜ 筛选（统一入口）｜ 导出（次级，靠右）。
- **条件行**：**仅在有筛选时出现**，逐项 ×+ 清除全部。

与现状相比少了什么：来源下拉不再常驻、状态胶囊不再常驻（收进「筛选」）、
导出不再是并列主按钮、无筛选时不占行高。

## 三态原型

`docs/prototypes/ux05-phaseA.html`：默认态 / 筛选生效态 / 扁平总览。

## 与 HEAD-B+ 的差别

| | HEAD-B+ | HEAD-NEW |
|---|---|---|
| 来源/状态 | 常驻控件 | 收进「筛选」，只在条件行显示结果 |
| 搜索 | 占满整行 | 有最大宽度，右侧留出筛选/导出 |
| 行数 | 固定两行 + 条件提示 | 两行，且条件行按需出现 |
| 拥挤来源 | 5 个常驻控件抢宽 | 常驻 1 个搜索 + 2 个按钮 |

**待用户确认后 Phase B 才替换正式 UI。**
