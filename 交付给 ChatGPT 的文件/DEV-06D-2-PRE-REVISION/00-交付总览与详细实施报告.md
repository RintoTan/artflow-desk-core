## 4. 技术发现（附证据）

1. **后端的"未排期"与时间线的"未排期"不是一回事。**
   `domain/dashboard.rs` 按 `planned_delivery_date IS NULL` 计数；时间线只在"起止都没有"时把订单移出轨道。所以"只有开始日期"的单：指标算未排期，时间线照画。原型按此实现，`full` 场景指标 2 / 时间线未排期 1。**要么统一口径，要么在 UI 上写清**。

2. **反向区间在正式库里不可能出现。**
   `orders` 有 `CHECK (planned_delivery_date >= planned_start_date)`。原型里的"日期顺序异常"只是防御性渲染，不是真实状态 —— 报告里不应把它当作待修缺陷。

3. **`DashboardPage` 目前没有快捷入口。**
   任务书假设的"原有快捷入口"在代码里不存在（只有指标卡 + 提醒说明）。本轮没有凭空加一个新的快捷入口区块。

4. **`scheduleBar` 可以复用，但不能直接用来画多行。**
   `barModel` 的输出是百分比，窗口由调用方给；多订单需要统一窗口 + 日期刻度，因此新增 `timeline.ts`（窗口/刻度/像素）而不改 `scheduleBar` 的任何导出。

5. **macOS 上给滚动条上色 = 失去 overlay。**
   实测：`scrollbar-color` 一加，`offsetWidth − clientWidth` 从 0 变 15。与 Chrome 官方"设宽度即强制经典滚动条"的说明一致，说明 WKWebView 侧也极可能同样（**未证实**）。这是 SCROLLBAR-01 改为平台分治的直接原因。

6. **`scrollbar-color` 的 Safari 支持是 26.2，不是 18.2。**
   18.2 只补了 `scrollbar-width` 与 `scrollbar-gutter`（WebKit 官方发布说明）。任何"18.2 三件套齐了"的说法都是错的。

7. **`scrollbar-width/color` 与 `::-webkit-scrollbar` 的压制方向容易记反。**
   标准属性非 `auto` 时，UA 忽略伪元素 —— 不是反过来。两者混用会得到"看起来没生效"的结果。

8. **`scrollbar-gutter: stable` 在 overlay 下完全无效。**
   想靠它消除"内容变多 → 滚动条出现 → 布局抖动"，只在 Windows 这类经典滚动条平台成立。现有 `.main` 使用它是正确的（macOS 无副作用）。

9. **画廊不需要新表。**
   v4 已经有 `attachments.role` 与 `gallery_visible`，v5 用触发器保证"可展示 ⇒ 必须是成品"。画廊 = 一条 `WHERE gallery_visible = 1` 的查询 + 分组。

10. **跳级不会污染完成次数统计。**
    完成次数按 `completed` 事件计；跳级不产生 `completed`。但 `order_events.kind` 的 CHECK 列表里没有 `stage_skipped`，要加就是迁移级改动。

11. **正式库仍是 schema v3。**
    v4/v5 已实现在代码里，但正式代际未升级。DEV-06D-4 依赖 v4 字段，切代际的时机必须在画廊之前定。

12. **容器查询不能作用于容器自身。**
    原型里 `@container workspace { :root { --info-w } }` 是无效写法（容器查询只能影响后代）。这是 900px 下信息列宽度不生效的根因，已改为落在 `#timelinePanel` 上。**实施时同样要注意**。

### 5.1 A 时间线

- **修改前的问题**：上一版原型是独立导航页、假空状态、单端日期伪造区间、900px 宽度算错、行无交互、越界标记错位。
- **修改后**：嵌入工作台第 2 个模块；四尺度真实重算；单端只画标记；越界只给箭头；左侧 178–300px 固定列 + 右侧独立横滚；行链接 + 键盘可达；三种真实空状态；6 套虚构数据集可切换（含 16 单密集）。
- **日期算法**：整数天序号；`parseDayKey` 回读校验拦截 2-30；月/年按自然月对齐；周按周一整周；月位移夹月末；区间含首尾两天；单日最小宽 22/14/7/3px（日/周/月/年）。
- **各尺寸**：900 → 轨道 369px、KPI 3 列、行高 52；1400 → 747px、4 列、56；1680 → 1027px、8 列、56。
- **测试**：53/53（见 04）。
- **截图**：01–11 + 联系表。
- **未解决**：7 条未决（见 §10）。

### 5.2 B 滚动条

- **现状**：全站 0 处自定义滚动条样式；5 处 `scrollbar-gutter`；11 个滚动容器。
- **macOS**：保持原生 overlay（本轮实测上色即失去 overlay）。
- **Windows**：`scrollbar-width: thin` + `scrollbar-color`（Chromium 121+），必要时叠伪元素。
- **CSS 可行性**：结论表见 02 §4，每条带来源；两条"未证实"（系统设置交互、WebView2 自动隐藏跟随）。
- **视觉状态**：4 状态 × 2 主题，数值见 02 §3。
- **回退**：默认原生 → `@supports` 渐进 → `forced-colors` 全退。
- **无障碍**：不动 overflow；上色后拇指 ≥3:1；不自绘以规避 2.5.7。
- **未验证**：WKWebView / WebView2 全部实机项。
