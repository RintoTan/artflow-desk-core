## 三、CAL-UI-15 连续滚动（核心边界已修，焦点同步未修完）

### 1. 找到的硬边界

```ts
const MAX_BACK_WEEKS = 60; const MAX_FWD_WEEKS = 60;
if (todayWeek - nextStart > MAX_BACK_WEEKS * 7) return;   // ← 直接拒绝扩展
```

滚到距今 ±60 周时 `extendWeeks` 直接 `return`：列表不再增长 → 滚动到底 → 用户感到"卡段/突然停止"。

### 2. 已修

- 改为有界窗口 `MAX_WEEKS = 104`：**到上限时裁掉另一端**而不是拒绝扩展；
- 裁剪头部 12 行时按 `12 × rowH` 回退 `scrollTop`，视口不跳（`trimHeadRef`）；
- 滚动目标（今天/跳转）优先于"保持视口中心"的补偿分支，避免补偿提前 return 吞掉跳转。

### 3. 验证（Blink，程序化 scrollTop，非真实滚轮）

```
初始          29 周 / 203 天
向下扩展 6 次  104 周 / 728 天   dup 0  gap 0
向上扩展 8 次  104 周 / 728 天   dup 0  gap 0
```

**日期无重复、无缺失**，跨越约 1.9 年仍连续。

### 4. **未修的真实缺陷**

深度滚动后点「今天」：滚动位置回到了正确的日期（视口中心落在 11 月），
但**月份标题显示 `2026 年 8 月`**——标题（`visibleAnchor`）与视口内容脱节。
根因尚未定位完（怀疑修完 `rangeStart` 裁剪后，`handleScroll` 的多数票用了旧的 `rangeStart` 基准）。
按真相记录：**`FAIL`，未修**。

另外：`handleScroll` 每帧对 7×可见行做 `getBoundingClientRect` 级别的读，节流未做 →
快速滚动下的卡顿**未验证**（原生滚轮无法注入，见第五节）。
