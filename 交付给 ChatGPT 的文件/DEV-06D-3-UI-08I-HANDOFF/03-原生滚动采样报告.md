# 03 · 原生滚动采样报告

采样方式：页面内 `setInterval(25ms)` 记录 `scrollTop / rowH / 标题 / 视口顶部行起始日`，
滚轮用 afctl `wheel` op（`CGEventCreateScrollWheelEvent` → `NSEvent` → `[win sendEvent:]` → WKScrollView）。

## 一、修复前（基线 ca0cdd0）

```
samples 226
rowHs   [114, 136]          ← 同一次滚动出现两种行高
titles  ["2026 年 11 月","2026 年 12 月"]
drops   6                   ← 18 次滚轮中 6 次向下跳变
```

## 二、修复后

```
samples 227
rowHs   [114]
drops   0
titles  ["2026 年 11 月","2026 年 12 月","2027 年 1 月","2027 年 2 月","2027 年 3 月"]
top     1306 → 3466（单调）
```

长程 60+60 次：

```
down  samples 470  back 0  maxBack 0  months 27  2026 年 11 月 → 2029 年 4 月
up    samples 465  back 0  maxBack 0  months 27  2029 年 4 月 → 2026 年 11 月
```

（`back` = 与滚动方向相反、且视口顶部日期倒退 > 0 的采样数；`maxBack` 为其最大倒退天数。）
