## 三、快捷键：代码核对结果

核对对象：`src/lib/shortcuts.ts`（`usePageShortcuts`）与四个页面的实际绑定。

| 键位 | 实现 | 绑定页面（代码事实） | 页面文案 |
| --- | --- | --- | --- |
| ⌘N | `onNew` → 打开新建表单 | Templates（`creating`）、Clients（`creating`）、Orders（`attemptCreate`） | 订单、客户、流程模板 |
| ⌘S | `onSave`，页面内部判 `dirty && !busy` | Orders（`saveDraft`）、Clients、Templates、Settings（`apply`） | 订单详情、客户、流程模板、设置 |
| ⌘F | `onFocusSearch` → `searchRef.focus()` | 仅 Orders | 订单列表 |
| ↑ / ↓ | `onMoveSelection(±1)`，`isEditableTarget` 时跳过 | 仅 Orders（`moveCursor`） | 订单列表 |
| Enter | `onOpenSelection` → `attemptSelect(cursorId)` | 仅 Orders | 订单列表 |
| Esc | 不走 `usePageShortcuts`：模态由 `modalStack` 的栈顶判定；页面级 Esc 见 Orders（关闭看板/表格详情）、Calendar（清焦点） | 全局模态 + 订单详情抽屉 | 全局（含看板/表格详情） |

与预期表的差异（已按代码修正文案）：

1. **⌘N 不含设置页**——设置页只绑定了 `onSave`；
2. **⌘S 包含设置页**——预期表没列，实际有；
3. Esc 不是"所有页面都监听"：模态栈 + 两个页面级处理器，且**有未保存修改时不关闭抽屉、只提示**。

## 四、行为说明（写进页面，且都能在代码里对上）

| 说明 | 代码依据 |
| --- | --- |
| 方向键只移动光标，不改队列顺序 | `moveCursor` 只改 `cursorId`；队列改动走 `reorder` |
| Enter 才打开 | `onOpenSelection` 调 `attemptSelect`，`moveCursor` 不选单 |
| ⌘S 仅在脏时保存 | 各页面 `if (dirty && !busy)` |
| Esc 只关最上层 | `modalStack.topModal()` / `isTopModal(id)` |
| 输入框内方向键/Enter 不切单 | `isEditableTarget()` 覆盖 input(文本类)/textarea/select/contentEditable |

平台：只写 macOS 的 ⌘；没有写 Ctrl，并加了一句「其他平台差异尚未验证」。
