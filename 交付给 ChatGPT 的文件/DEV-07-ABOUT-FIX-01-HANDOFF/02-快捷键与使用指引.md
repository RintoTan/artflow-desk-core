# 02 · 快捷键与使用指引

## 一、快捷键主题（第 2 个折叠项）

| 快捷键 | 功能 | 适用范围 |
| --- | --- | --- |
| ⌘ N | 新建 | 订单、客户、流程模板 |
| ⌘ S | 保存当前修改 | 订单详情、客户、流程模板、设置 |
| ⌘ F | 聚焦搜索框 | 订单列表 |
| ↑ / ↓ | 移动键盘光标 | 订单列表 |
| Enter | 打开光标所在订单 | 订单列表 |
| Esc | 关闭最上层弹窗 | 全局（含看板/表格详情） |

表下 6 条说明（页面原文）：

1. ↑ / ↓ 只移动键盘光标，不会改变订单在队列里的顺序。
2. 按 Enter 才会打开当前光标所在的订单。
3. ⌘ S 只在存在未保存修改时执行保存；没有改动时不会写入任何内容。
4. Esc 按弹窗层级处理，只关最上面那一层；看板与表格视图下会关闭右侧详情，若详情里还有未保存的修改，会提示先保存或撤销。
5. 光标在输入框、文本域或下拉框里时，方向键与 Enter 只作用于输入内容，不会触发订单列表的光标移动。
6. 当前展示的是 macOS 键位；其他平台的差异尚未验证。
