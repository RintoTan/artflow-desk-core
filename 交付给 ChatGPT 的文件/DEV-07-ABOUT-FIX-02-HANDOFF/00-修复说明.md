# 00 · 修复说明（DEV-07-ABOUT-FIX-02）

## 原因

`src/styles.css` 里说明文字被加了一个**固定行宽上限**：

```css
.about-intro { max-width: 74ch; }   /* ≈619px */
```

`ch` 是字符宽度单位、与卡片宽度无关，所以无论窗口多宽，段落都被钉在 ~619px：
宽屏时右侧留下大片空白、行断点由这个固定值决定，而不是由卡片可用宽度决定。

另外 `.about-page` 是 `.main-inner`（flex 列）的子项，默认 `min-width: auto`，
一旦卡片里出现不可断的长 token（数据代际 id、数据目录路径），整块内容就不肯收缩。

## 改动

只改 `src/styles.css`，三处：

```css
.about-page { min-width: 0; }            /* flex 子项允许收缩 */
.about-page > .panel { min-width: 0; }   /* 面板同样跟随容器收缩 */
.about-intro {
  max-width: none;                       /* 去掉固定行宽 */
  overflow-wrap: break-word;             /* 长 token 不撑出卡片 */
}
```

未改 `AboutPage.tsx`、文案、字号、行高、颜色、卡片布局与其它页面。
