# 02 · 软件信息与模块说明

## 一、软件介绍（页面文案）

> ArtFlow Desk Core 是一款面向独立画师的本地优先桌面委托管理工具，帮助画师管理委托订单、客户资料、制作流程、交付排期和历史记录。
>
> 软件以本地数据存储为基础，提供订单管理、制作进度追踪、附件管理、数据备份与恢复等功能，不依赖云同步，也不需要客户注册在线账号。
>
> Web 端 ArtFlow Desk 与桌面端 ArtFlow Desk Core 属于同一产品体系下的两个独立产品：工程、数据与发布彼此独立，不共享数据库。

## 三、功能模块（7 个，均对应已实现功能）

| 模块 | 一句话 | 说明要点 | 对应实现 |
| --- | --- | --- | --- |
| 工作台 | 打开就能看到今天该做什么 | 订单状态计数、三日内/今天到期/已逾期、本月完成次数、跨订单时间线 | `DashboardPage` + `stats`/`orders` 查询 |
| 订单管理 | 委托从新建到交付的全过程 | 三种视图与筛选、新建/编辑/复制/取消、队列排序、阶段推进与跳级、制作历史、参考图片 | `OrdersPage` + `domain/orders` + `lifecycle` |
| 客户管理 | 甲方资料集中管理 | 名称/联系方式/备注、标签分类、订单关联与客户下钻 | `ClientsPage` + `client_tags` |
| 流程模板 | 不同委托走不同流程 | 模板增删改、下单生成副本、改模板不影响已有订单历史 | `TemplatesPage` + `stage_templates` |
| 日历排期 | 按日期看排期、拖动改期 | 月/周视图、计划区间绘制、拖动改期写排期历史 | `CalendarPage` + `reschedule` |
| 历史统计 | 回看完成了多少 | 月度完成与收入、客户/模板下钻、CSV 导出（按当前筛选） | `StatsPage` + `export_orders_csv` |
| 系统设置 | 外观、时区、备份与维护 | 主题/强调色/图标、工作时区、备份与恢复、附件维护 | `SettingsPage` |

未实现的功能一律没有写进去：没有自动定时备份、没有云同步、没有回收站/永久删除、没有作品集导入、没有多用户权限。

## 四、术语控制

页面正文（模块卡与指引）刻意避开开发术语：不出现 Rust、SQLite、IPC、Schema、Migration。
唯一保留的技术名词是「SQLite」与「日志模式」，且**只在数据环境区块的原始状态字段里**（这些字段原本就存在，属于真实环境信息，改写成"数据库引擎"反而失真）。
