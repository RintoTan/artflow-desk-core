# 03 · 数据兼容与安全报告

## 一、数据库结构版本

- 应用支持：`APP_SCHEMA_VERSION = 7`
- 迁移链：v1 → v2 → … → v7，全部为 append-only 迁移，**本轮未修改 v1–v7 任何既有迁移文件**
- 顺序版本：结构版本（7）与备份格式版本（1）独立管理，互不推断

## 二、generation 机制

```
{root}/
├── generations/gen-<uuid>/database.sqlite
│   └── …/attachments/{originals,thumbs,quarantine}
├── state/active.json            # 指针（原子写）
├── state/highwater.sqlite       # 独立编号高水位
├── state/backup.json            # 本轮新增：上次备份时间 + 提醒周期
├── environment.json
├── backups/                     # 本轮新增：默认导出目录 + 恢复前快照
└── recovery/                    # 本轮新增：失败现场隔离目录
```

`state/backup.json` 刻意**不放进业务库**：提醒是「这台机器上次什么时候备份」的本机状态，若写进业务库，恢复一份旧备份会把提醒基准一起倒回过去。

## 三、原始数据库保护

- 恢复全程只在**新代际目录**里解包与迁移；
- 当前活动代际的 `database.sqlite` 与附件 **不被写入、不被删除、不被 rename**；
- 迁移只发生在恢复出来的新副本上，不触碰源数据；
- 恢复成功后**不删除旧代际**，保留回退能力。

## 四、迁移链

- 恢复时若备份结构版本 < 7，调用既有 `migrations::migrate_to()`；
- 不允许改 Manifest 里的版本号伪装兼容；
- 不允许删除旧字段或忽略未知数据；
- 迁移后再跑 `integrity_check` + 版本断言 + `validate()`，不达标即整步失败。

## 五、高水位与编号连续性

- 高水位在 `state/highwater.sqlite`，独立于业务库，随 Manifest 的 `numberHighWater` 逐年备份；
- 恢复时逐年 `max(本机, 备份)`，**只升不降**；
- 新机器（无本地高水位）直接采用备份值；
- 实测：备份 `2026→14`，恢复前后本地仍为 `2026→14`，`raisedWatermarks` 为空；
- 单测 `restore_never_lowers_a_newer_local_watermark` 覆盖「备份后继续分配编号再恢复」的场景。

## 六、外键约束

- 恢复时对解出的库执行 `PRAGMA foreign_key_check`，有任何违规即拒绝恢复；
- `order_events.order_id → orders(id) ON DELETE CASCADE` 在迁移测试中单独验证（删订单后事件归零）。

## 七、原图完整性

- `attachments.state='ok'` 的每一行，`rel_path` 必须在解包结果中存在，缺失即 **拒绝整套恢复**（并用前 3 个样例路径说明缺什么）；
- 缩略图缺失只计数（`missingThumbs`），不阻断——缩略图可由原图重建；
- 恢复后 `attachment_jobs` 里属于旧代际的 pending 行置 `failed` 并写明「恢复后失效：任务来自旧代际」，避免对不存在的文件重试。

## 八、恢复前安全快照

- 每次恢复前自动执行一次**完整导出**（`backups/pre-restore-<时间戳>.zip`），包含数据库 + 附件 + Manifest + SHA-256；
- 快照失败 → 立即取消恢复，当前数据一个字节都不动；
- 该快照不依赖用户事先手动导出。

## 九、失败隔离

| 阶段 | 失败后 |
| --- | --- |
| 校验 | 不建目录 |
| 恢复前快照 | 取消，不建新代际 |
| 解包 / 体检 / 迁移 / 引用核对 | 新代际目录整体挪到 `recovery/failed-restore-<时间戳>-<id8>/`，`generations/` 保持干净，`active.json` 未动 |
| 高水位合并 | 同上 |
| 切换后崩溃 | `recovery/state.json` 留下 phase=restore，指针已指向**已验证**的新代际 |

`recovery/` 里的现场**不自动清理**。
