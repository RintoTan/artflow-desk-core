## 切换场景的前提

场景在进程启动时由 `AF_MINIDESK_QA_SCENARIO` 决定，**不能热切换**。当前你有一个 QA 应用实例
跑在 `seeded` 上（持有该目录的独占锁），切到时间线场景需要先退出它，再用对应 `npm run qa:timeline-*` 启动。

## 清理方式

```bash
# 单场景
rm -rf "$HOME/Library/Application Support/dev.artflow.minidesk.qa/timeline-terminal"

# 或重新生成（幂等，无需先删）
npm run qa:seed:timeline-terminal
```

不建议一次删掉整个 `.qa` 根：那会连带清掉 `seeded` 与 `clean` 两个既有场景。
